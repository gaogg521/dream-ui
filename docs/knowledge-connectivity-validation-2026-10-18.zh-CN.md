# 企业连接与知识库修复验收（2026-10-18）

本记录对应本地 DEV，覆盖桌面、企业服务与内网 Office。不是生产部署或安装包发布记录。历史交接中的地址、运行版本和“接线未合入”结论须结合本记录与当前 Git 核实。

## 连接与离线行为

- 侧栏和企业页面共用实际组织上下文的连接结果，区分检查中、已连接、连接异常及登录失效。保存过服务器地址或会话不等于在线。
- 每 15 秒探测一次，单次组织上下文请求 10 秒超时。连续不可达 15 分钟后关闭企业模式，切回个人服务；保留企业地址和会话供用户重新连接，同时给出提示。
- 成功响应清零离线计时；401/403 等可达的认证、权限拒绝不累计不可达时长。计时按服务器持久化，切换地址、关闭模式或重新启用会开始新周期。
- 企业模式下，页面与知识 MCP 使用同一企业端点。未登录、连接失败时明确报错，不把个人知识检索伪装为企业结果。切回个人模式后才使用本机服务。
- 同窗口配置变更即时通知主进程；设备标识随治理请求发送；异步设备标识查询不会覆盖更新后的端点。更换服务器先清除旧会话，迟到的旧上下文不再回写当前页面。
- 短暂断网保留已同步的企业资源缓存并暂停同步，不能把暂时查询失败当作已退出组织。项目组切换会立即重新同步。

真实 DEV 使用故障代理与加速时钟验证：健康连接、断网异常、MCP 报错、14 分钟仍为企业模式、恢复清零、401 不切换、连续 15 分钟切回个人并保留会话、切换后个人 MCP 恢复。产品阈值未缩短。证据：`D:/dream/outputs/knowledge-heartbeat-realdev-1018.json`。

## 知识正文与检索

- 正文修改与旧向量片段、全文索引失效在同一事务提交；清空正文或新正文索引失败时，旧正文不能继续被检索。
- 向量生成返回后，在写事务中核对正文版本；延迟返回的旧任务不能复活旧片段或覆盖新版索引状态。
- 查询向量服务故障时，使用相同权限过滤的词法检索降级。词法结果分数可通过现有任务注入门槛；全文能力不可用时仍返回明确错误。
- 实测个人与企业服务的保存、自动索引、语义检索、清空后无旧命中、原件及 Range、私有文档列表/正文/检索/原件隔离。独立故障服务确认 Embedding 不可达时搜索仍为 HTTP 200 且找到有权限的资料。

证据：`D:/dream/outputs/knowledge-fix-live-1018.json`（29 项含清理全部通过）、`knowledge-fix-embedding-failure-1018.json`、`knowledge-fix-mcp-stdio-1018.json`。真实 MCP stdio 完成初始化、工具发现与企业已保存正文检索。

- 修复桌面 preload 同名启动桥重复暴露导致新 DEV 启动白屏的问题。
- Word 在真实桌面中键入；Excel、PPTX 在独立企业控制台浏览器中键入。三格式均核对自动保存、下载原件 XML、提取正文与知识检索中的新标记。
