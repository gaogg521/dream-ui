# 手机版 WebUI 会话交付方案

## 产品边界

手机端不是另一套 App，也不新建会话库、接口或 Agent 运行时。它是用户通过手机浏览器（或安装为 PWA）访问现有 WebUI。

手机是控制面；桌面设备或企业服务器仍是执行面，负责 Agent 运行时、本地文件、模型凭据和审计数据。

## 两种接入方式

| 方式           | 入口                            | 复用能力                                        |
| -------------- | ------------------------------- | ----------------------------------------------- |
| 本机局域网访问 | 桌面 WebUI 的二维码或局域网地址 | 现有登录、REST API、WebSocket、会话与任务运行时 |
| 企业远程访问   | 企业 HTTPS 地址                 | 同一会话和渲染契约，叠加企业身份与授权          |

两者是部署和接入方式，不是两套手机 UI。

## 交付阶段

### 第一阶段：会话连续性

- 保留现有响应式会话布局、移动端抽屉、操作面板、动态视口及安全区支持。
- WebSocket 重连后，以持久化消息页为准，拉取“最新游标之后”的全部页面。
- 已在界面的实时消息原地更新；真正遗漏的新消息追加到末尾，不把读者拉回旧位置。
- 保留旧历史的无限滚动及搜索结果的消息锚点跳转。

### 第二阶段：移动端阅读与操作

- 在 390px 和 430px 视口审计标题栏、会话列表、消息流、工具摘要、审批卡、文件产物、预览覆盖层和输入框。
- 浮动操作必须至少 44px，且避开浏览器底部安全区和输入框。
- 桌面专属操作不放进移动端标题栏；模型与次要操作继续放在已有的移动端操作面板。
- 审批选项、结构化提问的选项以及提交/拒绝按钮均维持至少 44px 的触控尺寸。

### 第三阶段：设备与企业安全边界

- 远程 PWA 安装和 service worker 必须使用 HTTPS。
- 本地 WebUI 仅在明确受信网络内暴露；若要暴露到公网，必须另行引入可撤销的设备配对和审计记录，不能复用或弱化局域网开关。
- 用户、工作区、组织和共享会话的授权必须由服务端执行；响应式 UI 不能成为权限边界。

## 验收矩阵

| 场景                   | 验收证据                                               |
| ---------------------- | ------------------------------------------------------ |
| 阅读很长的会话         | 旧页加载不重复，滚动位置不突跳。                       |
| 手机进入后台或切换网络 | 重连后补齐每一页持久化新消息，实时消息原地对齐。       |
| Agent 请求操作         | 审批卡和提问卡在 390px 宽度可见且可点击。              |
| 读者停在旧消息         | “跳至最新消息”便于单手触达，且不遮住输入框。           |
| 打开预览或工作区       | 在窄屏覆盖会话，不卸载会话本身。                       |
| PWA 模式               | iOS/Android 的安全区和动态视口不会遮住标题栏或输入框。 |

## 验证要求

- 单元测试覆盖游标追补、去重、异常游标响应，以及移动端浮动操作。
- 浏览器验证使用 390×844 与 430×932；带认证测试账号和种子长会话时，还须人工验证审批卡、提问卡和输入框。
- Vitest 绿灯不足以代表完成：如有 worker 失败或实际执行的测试文件少于已知基线，则结果无效。

## 本次实现记录（2026-09）

三阶段均已落地，代码分布在 `dream-ui` 与 `dream-core` 两个仓库：

- 会话连续性：WebSocket 恢复连接后，客户端按游标分页补齐服务端已持久化的新增消息；合并时保留实时消息的原地更新并对历史结果去重。
- 移动端操作：跳至最新消息、结构化提问选项/提交拒绝操作及审批选项均满足最小 44px 触控尺寸，并为底部安全区预留空间。
- 设备安全：扫码、密码与 MFA 登录都签发绑定设备的会话；服务端仅保存令牌摘要。设备可列出、可单独撤销，撤销会阻止后续请求与令牌刷新，并记录配对、撤销与最后活跃信息。

### 接口与迁移

- 数据库迁移：`dream-core/crates/dream-core-db/migrations/058_webui_device_sessions.sql`。
- `GET /api/auth/devices`：读取当前账号尚未撤销的设备会话。
- `POST /api/auth/devices/{device_id}/revoke`：撤销当前账号的指定设备会话。

### 已执行验证

- `dream-ui`：目标 Vitest 测试、类型检查和格式检查通过；以 390×844、430×932 视口验证 WebUI 壳层与安全区布局。
- `dream-core`：认证包单元测试、扫码/登录路由回归、设备仓储的创建—活跃—撤销回归测试，以及应用级 `cargo check` 通过。
