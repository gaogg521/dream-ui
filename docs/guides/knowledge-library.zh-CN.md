# 资料库：个人资料、团队空间与文档编辑

更新日期：2026-10-14。本文描述当前源代码行为，不代表安装包已发布。

## 使用

- 资料库左侧显示个人资料和有权限访问的团队空间；目录支持拖拽宽度、收起、双击适配及键盘调整。
- 文档在目录右侧直接阅读和编辑。Markdown 默认进入图文编辑器，支持标题、加粗、斜体、列表、图片和表格，也可切换 Markdown 源码。
- 可以粘贴格式化文字、图文及表格，或拖入图片。图片支持 PNG、JPEG、GIF、WebP，单张最多 5 MB；图片以内嵌数据保存，文档保存请求最多 16 MB。
- 表格工具提供插入表格、添加行列、删除表格；CSV 使用独立表格编辑器。HTML 在隔离 iframe 中预览，不允许脚本执行。
- 停止输入约 1.2 秒后自动保存。返回资料库和切换阅读模式前补存最后一次编辑；保存期间可以继续输入，后续修改串行保存。
- 状态显示“保存中”“已自动保存”或“保存失败，可重试”。失败保留当前编辑内容，可用保存按钮重试。新建文档持续更新同一条记录。
- 列表搜索同时查找标题与已保存正文，不要求向量索引先完成。语义检索属于单独的检索能力。

## 导入与权限

桌面版通过本地文件选择器导入 PDF、Office 等资料，由主进程提取文字，再登记和保存。个人资料使用 personal scope，仅本人可见；团队资料按服务端空间、成员和授权策略访问。企业管理员可维护团队资料，普通成员可阅读其有权访问的正文。

浏览器 WebUI 的文件选择与本地桌面 IPC 不等价；本次尚未补齐浏览器文件上传导入。外链分享、HTML 应用发布不在本次范围。

## 默认索引

保存非空正文后，后端在后台排队构建向量索引，保存操作无需等待索引完成。优先使用管理员保存的配置，其次使用部署环境配置；未配置时使用 `local://embedding` 的本地多语言模型。首次初始化需要下载模型；缓存位于 ONE_DATA_DIR/models/embedding，未设置时使用 Windows LOCALAPPDATA/OneWork 或 HOME/.cache/onework 下的 models/embedding。

本地推理不向外部嵌入服务发送正文，但首次下载、完全离线环境以及企业镜像分发仍需单独验收。历史待处理文档不会因启动自动回填；需重新保存或手动处理。

## 原文件阅读与内置学习指南（2026-10-14 补充）

原文件与检索正文分开保存。新增原文件上传/下载接口 `/api/one/devops/rag/documents/{id}/source`，沿用文档读写权限；文件存放在数据目录下的 `knowledge-sources`，不暴露本机路径。单个原文件上限 100 MiB，支持单段 Range 请求。

个人端导入保留原文件，阅读页依据文件类型显示 PDF、图片、音视频或隔离 HTML；不支持的格式提供原文件下载。旧的纯提取文本资料可补充原文件。PDF 阅读已在个人 WebUI 实测原始页面、缩略图、页码和缩放；企业后端本轮接口尚需更新后再做原文件联动验收。Office/设计文件在线编辑尚未实现。

个人端和企业端内置两篇原创教程：《一分钟上手资料库》《资料库使用指南》。首页卡片和目录中的学习入口均可页内打开，正文提供中文和英文。教程不自动创建用户文档，不占用个人资料列表和搜索结果。

完整差距与实测边界见 `docs/knowledge-library-product-gaps.zh-CN.md`。自动保存不等于版本历史，静态 HTML 预览不等于数据工作台。
