# Get started with your library

## 1. Create a visual document

Create a document in My files. Add a title, text, an image or a table. Markdown source mode is available for existing Markdown content. Wait for the save status and reopen the document to check it.

## 2. Organize a project

Keep personal drafts in My files and shared work in an authorized team space. Group related notes and attachments in folders. An original file preserves its layout; extracted text serves search.

## 3. Find and reuse information

Search using a title or a keyword from the saved body. Semantic retrieval additionally requires a ready index. To use material in an AI task, copy the relevant passages and explain the intended outcome. Automatic task attachment and write-back are not complete yet.
