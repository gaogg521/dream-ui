# Library user guide

## Customer files

Create one folder per customer. Keep requirements, meeting notes and delivery attachments together. Record the current need, the next step, the owner and the deadline in a Markdown table. Keep private notes in personal storage.

## Meeting notes

Use an Agenda → Decisions → Actions structure. Add whiteboard images and an action table. Reopen after autosave. To ask AI for an action plan, supply the relevant passages; do not assume it can read all personal or company files automatically.

## Project lists

Use CSV for basic rows and columns and Markdown for explanations. Live HTML dashboards bound to CSV are not available yet.

## Originals and search

Original files preserve layout and media. Extracted text is used for search and indexing. Older text-only records need the original file attached again. PDF, image and media previews depend on the actual file. DOCX and PPTX have local original-file previews. Excel has a worksheet data preview (up to 2,000 rows and 100 columns, without charts or original styling). Use Edit to modify DOCX, XLSX and PPTX originals. The personal desktop app uses an offline editor; enterprise editing requires an administrator-configured intranet service. Wait for Saved before leaving. Keep the editor open and retry if saving fails. Download the original when editing is unavailable. Download design files to open them in the corresponding application.

Keyword search covers titles and saved bodies. Uploading a scanned image or a video does not automatically make its visual content or speech searchable. Semantic retrieval needs a ready index and a configured model.

## Saving and access

Wait for autosave status. Preserve your text and retry after a save failure. Choose the correct personal or team location and confirm membership and access. Read access does not imply edit access.

## Current limits

Anchored comments, AI selection edits with accept/reject, collaborative Office editing, one-click task attachment and automatic write-back remain incomplete. External publishing is outside this internal-library iteration.
