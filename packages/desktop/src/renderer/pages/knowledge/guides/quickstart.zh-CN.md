# 一分钟上手资料库

把一次工作的资料留下来，让下一次工作更容易开始。

## 1. 建立第一份图文文档

在「我的资料」中选择「新建文档」，填写标题，例如「客户沟通记录」。直接编辑正文，可以排版文字、插入图片和表格，也可以粘贴截图。Markdown 源码模式适合已有 Markdown 内容。

修改会自动保存。离开前查看保存状态；若出现保存失败，先保留内容并重试。

## 2. 按项目整理资料

个人草稿放在「我的资料」；企业内需要协作的内容放在有权限的团队空间。用文件夹归类客户、项目或部门资料，让同一件工作的文档与附件放在一起。

导入文件后，检查是否能够打开原文件，以及正文是否已提取。原文件用于阅读，提取正文用于搜索，两者不是同一份展示内容。

## 3. 找到资料并继续使用

在搜索框输入标题或正文中的关键词，例如「交付时间」。语义检索需要索引完成；关键词搜索和语义检索用途不同。

打开文档阅读或继续编辑。需要让 AI 参考资料时，可以先复制相关内容到任务中，并说明要完成的工作。自动加入任务和修改回写尚未形成完整流程。

## 第一次使用检查表

- [ ] 创建一份有标题、有正文的文档
- [ ] 插入一张图片或一个表格
- [ ] 等待自动保存，重新打开确认内容
- [ ] 用正文中的关键词搜索一次
- [ ] 团队资料确认所属空间和访问权限
