# 资料库使用指南

资料库适合沉淀工作资料。先按实际工作建立目录，再选择合适的文档类型。

## 场景一：客户档案

为每个客户建立文件夹，把需求、沟通记录和交付附件放在一起。新建 Markdown 文档，使用下列表格记录关键事实：

| 信息     | 示例             |
| -------- | ---------------- |
| 当前需求 | 下周确认方案     |
| 联系记录 | 会议日期与结论   |
| 下一步   | 负责人、截止时间 |

正文保留明确的客户名称和关键词，方便以后搜索。面向团队的档案放入授权团队空间；私人备注保留在个人资料。

## 场景二：会议记录

使用「议题 → 决策 → 待办」结构。图片可以保存白板或草图，表格记录负责人和时间。会后再次打开文档，检查自动保存结果。

向 AI 提问时，附上相关段落并写明目的，例如「根据这些决定整理下周行动清单」。当前不要假设 AI 会自动读取所有个人或企业资料。

## 场景三：项目清单

简单行列数据使用 CSV 表格，说明和背景使用 Markdown 文档。可以分别保存项目说明、任务清单和参考附件。

CSV 当前适合基础数据维护。HTML 页面与 CSV 双向绑定、自动生成动态工作台属于后续能力，不是当前表格功能。

## 阅读原文件与搜索正文

原文件保留排版、图片或音视频内容；提取出的正文用于搜索和索引。旧资料若只留下提取文本，需要重新附加原文件才能恢复原始阅读体验。

PDF、图片和音视频可按原文件浏览。DOCX 和 PPTX 提供本地原件预览；Excel 提供工作表数据预览（最多 2000 行、100 列，不含图表和原始样式）。这些 Office 格式暂不支持原版在线编辑；设计文件请下载后使用对应应用。不要将「文件已入库」理解为「所有格式都能在线编辑」。

## 自动保存与索引

编辑文档后等待保存状态更新。保存失败时先保留正文，恢复连接后重试。索引处理可能晚于文档保存；语义检索没有命中时，先检查处理状态和模型配置，再尝试关键词搜索。

关键词搜索支持标题和已保存的正文。扫描图片、视频对白和未提取的附件内容，不会因为上传成功就自动成为可搜索正文。

## 团队使用

个人资料和团队空间有不同的访问范围。创建或导入前确认目标位置，协作前由管理员配置成员及权限。读权限不代表有修改权限；前端入口是否显示也不能代替服务端权限校验。

## 当前边界

定位评论、AI 选区修改与接受/拒绝修订、原生 Office 协同编辑、资料一键加入任务和成果自动回写，尚未完成。外链发布不属于本轮企业内部资料库范围。
