## 六个硬理由

### 01 · 快 5×——Team Mode 编队并行

Leader 拆任务、Teammate 同时跑，一次交付并行推进。同样任务约为某 Buddy 的 **5 倍**、某 Work 的 **3 倍**，作战记录一键导出。

<img src="./resources/adv/adv-speed.png" alt="速度快 · Team Mode 并行交付" width="100%">

### 02 · 独家桥接——官方 CLI 直接换成你的模型

OpenAI **Codex CLI** 和 Anthropic **Claude Code** 被厂商锁死在官方账号？One Work 在本机起一个兼容端点，官方客户端原样使用，底层直接走你自配的 MiniMax、DeepSeek、Kimi 或自建网关——纯本地转发，关闭即恢复。

<img src="./resources/adv/adv-bridge.png" alt="Codex / Claude CLI 一键桥接自配模型" width="100%">

### 03 · 隐私安全——数据与 Key 落本机

记忆、项目路径、API Key 全部保存在本机目录。远程 IM / WebUI 只是发指令，Agent 仍在你电脑上执行，**不经我们服务器中转**；操作可批准、可审计。

<img src="./resources/adv/adv-privacy.png" alt="隐私安全 · 数据与 Key 落本机" width="100%">

### 04 · 省钱 −35%——内置专家 + 技能复用

252 个编译期内置专家 + Skill 复用，减少重复 Prompt。同任务 Token 比某 Buddy 低约 **35%**、比某 Work 低约 **22%**。

<img src="./resources/adv/adv-cost.png" alt="省钱 · Token 消耗更低" width="100%">

### 05 · 企业就绪——后台向导 · 场景下发 · 资源审批

六步初始化（成员邀请 → 飞书/钉钉/企业微信/OIDC/LDAP 单点登录 → License 激活 → 组织架构 → 模型渠道 → 安全档位）。**场景**把技能、成员、资源授权打包成一键下发的工作环境；成员申请资源、管理员审批，全程留痕。

## 3 分钟上手

1. [下载 v3.0.14](https://github.com/gaogg521/dream-ui/releases)（Windows `.exe` / macOS `.dmg` / Linux `.deb`）
2. 首次启动 → **一键启用免费模型** 或配置自己的 API Key
3. 选 **IONE CLI** 或本机 Claude Code / Codex → 开聊
4. 需要桥接 → **设置 → Codex 桥接 / Claude 桥接**
5. 需要远程 → **设置 → WebUI** 或接入 IM 渠道

```bash
xattr -cr "/Applications/One Work.app"
```

或 **系统设置 → 隐私与安全性 → 仍要打开**。

<details>
<summary><strong>❓ FAQ</strong></summary>

**252 位专家要联网吗？** 不要，编译期打进二进制，断网可用。

**桥接会被封号吗？** 本质是本地换掉模型来源，不破解官方鉴权，关开关即恢复。

**企业版要连你们服务器吗？** 不要，数据在局域网内，授权离线激活。

**为什么看不到 Cursor Agent？** 需安装 Cursor Agent CLI 并在设置里扫描。

</details>
